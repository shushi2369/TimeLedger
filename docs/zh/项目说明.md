## 快速开始（新机器复现）
1. 安装 JDK 17 + Android SDK（或 Android Studio），SDK 路径写入 `local.properties`；
2. 恢复 `~/.gradle/init.d/mirrors.init.gradle` 与 `~/.gradle/gradle.properties`（见主文档附录A，国内网络必需）；
3. `gradlew :app:assembleDebug` 出包后 `adb install -r app-debug.apk`。
